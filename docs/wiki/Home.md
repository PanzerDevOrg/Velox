# Velox wiki

Velox makes a server faster when many items are lying on the ground. Big explosions, mob drops, or a storage room emptied onto the floor no longer make the server stall. Velox works out where all the items go in one batch, instead of one by one.

Players do not need to install anything. Velox runs on the server only.

- Minecraft: 1.21 to 1.21.11, and 26.1 to 26.3
- Loader: NeoForge, server only
- Needs: [Celeris](https://github.com/bichal/Celeris) 0.3.1.1 or newer, on the server
- Current version: 0.1.0
